# YouTube Client App Final Assignment

Throughout this Angular course, you will implement a comprehensive ToDo application. Please refer to the [Task](https://github.com/rolling-scopes-school/RS-Short-Track/wiki/9.-TODO-List,-client) for design guidelines.

## Task Requirements

**Setup and Initial Project Creation**

- Use the `@angular/cli` to create a new project with Angular v19 or later.
- Set up a new private repository on GitHub for the project and push the initial commit (Provide access to the github repository bullet `pulya10c`).
- Use Angular Material for UI components.
- Use SCSS as the default stylesheet.
- Migrate Angular application to ESLint with rules [AirBnB](https://github.com/airbnb/javascript).
